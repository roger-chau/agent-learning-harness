Project B · Parallel primitives · Milestone 3 of 5
A 256-bin histogram that stays fast whatever the data looks like.

Build: histogramRobust

Write histogramRobust(x, bins, n) for u8 input and a zero-initialised u32 output, and runHistogramRobust(x, bins, n), which returns an array of the stats of every launch you make.

It will be run on $n = 65{,}536$ values in three distributions:

  • uniform: random values 0–255;
  • constant: every value the same;
  • skewed: 90% one value, 10% random.

Your 3.3 privatised histogram takes about 1,400 cycles on uniform data but around 4,900 on constant data. The target: ≤ 2,600 cycles total on every distribution.

The chapter lists two families of fixes, combining before the atomic and spreading counters, and they trade off differently between uniform and skewed data. Measure before choosing. If you try warp aggregation, remember that warp operations must be reached by all lanes of the warp together (Chapter 1.4).

How it's checked

  • Correct on all three distributions, and on small sizes.
  • ≤ 2,600 total cycles on each distribution at $n = 65{,}536$.
