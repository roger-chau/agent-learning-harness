Project A · Imaging kernels · Milestone 2 of 3
Start from your A1 pipeline. Same kernels, same results, same rule about divergence. Now every kernel must also be coalesced.

What changes

Run your A1 pipeline and look at each kernel's coalescing. Two problems usually show up:

  1. Grayscale reads interleaved RGB. One pixel per thread means lane $\ell$ reads bytes $3\ell$, $3\ell+1$, $3\ell+2$. Each of those three load instructions spans 96 bytes, about 3 sectors, to deliver 32 useful bytes. That's roughly a third efficient, and no indexing trick fixes it: the data layout is the problem.
  2. Stencils with narrow blocks. With 16-wide blocks, a warp covers two half-rows. When it reads $x \pm 1$ or $x \pm 2$, each half-row straddles an extra sector.

The fixes

Grayscale: stage through shared memory. Let a block of $T$ threads handle $T$ consecutive pixels, which are $3T$ consecutive bytes. In three rounds, thread $t$ copies byte $k \cdot T + t$ of that range into a shared u8 array. Each round, a warp reads 32 consecutive bytes: one sector, fully coalesced. After __syncthreads(), thread $t$ reads its pixel's three bytes from shared memory at $3t$, $3t+1$, $3t+2$. Shared memory doesn't care about stride (and this pattern has no bank conflicts: neighbouring lanes share words, which broadcast).

const s = shared("rgb", 3 * T, "u8");

Watch the guards. The last block may have fewer than $T$ pixels, so bytes past the end of the image must not be read. An if around the byte copy would split warps whose pixels are all valid. Clamping the byte index with Math.min instead (Chapter 1.5) keeps them clean. And __syncthreads() must be reached by every thread, so put it outside any if.

Stencils: make warps span full rows. Use blocks that are at least 32 wide (for example 32×8), so a warp's reads at $x+k$ form one contiguous run of 128 bytes. That's 4 sectors when aligned, 5 when shifted.

How it's checked

  • Correctness, as in A1, on several sizes.
  • Coalescing: grayscale ≥ 95%. Both blur passes and Sobel ≥ 80%. (Shifted neighbour reads can't reach 100% without tiling; that's A3.)
  • Control flow: as in A1, warps that lie entirely inside the image must not diverge. The grayscale kernel is checked on its output pixels.

Same API as A1: runPipeline(rgb, w, h) returns { gray, blurred, edges, stats: [4 launch results] }.
