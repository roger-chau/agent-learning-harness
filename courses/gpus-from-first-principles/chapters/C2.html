Register tiling: break through the one-in-three ceiling.

Build: a register-tiled SGEMM

Write gemmReg(A, B, C, n) and runReg(A, B, C, n), which launches it and returns the stats. Each thread computes a tile of outputs (4×4 or larger) as an outer product from register-held values, loading slices of the shared tiles with ldg4. n is a multiple of 64. Pick block and thread tile sizes that give the 256×256 case enough blocks to use all 16 SMs.

How it's checked

  • Correct on 64×64 and 256×256.
  • ≥ 40% of FP32 peak (percentOfPeakFp32) on 256×256. The tiled kernel from C1 manages under 30%.

When you're stuck, compare fmaInstructions with everything else the stats report. Where are the non-FMA instructions coming from?
