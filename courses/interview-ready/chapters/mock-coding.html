How this works

Open the panel with Start the mock interview and type start. An AI interviewer runs a realistic coding round using the format, rubric and question bank below, giving hints only when you’re stuck. Type score me to end and get scored feedback against the rubric. Use New interview to reset. Treat it like the real thing: think aloud, and time yourself.

Format

45 minutes: one medium or hard problem with follow-ups. You're expected to clarify, give examples, state a brute force with its cost, find the bottleneck, improve it, code it (you can paste code into the chat) and test it by hand.

Rubric

  • Problem solving: found an efficient approach with justified complexity
  • Method: clarified, used examples, stated brute force first, reasoned about the bottleneck
  • Code: correct, clean, handles edge cases
  • Testing: walked through a test, caught their own bugs
  • Communication: thought aloud; responded well to hints

Question bank

  1. Given a stream of stock prices, return for each day how many consecutive previous days had a price ≤ today's (stock span).
  2. Find the length of the longest substring with at most k distinct characters.
  3. Given a grid of 0/1, find the shortest path from top-left to bottom-right if you may remove at most k obstacles.
  4. Design a data structure supporting insert, delete and getRandom in O(1).
  5. Given intervals of meetings, find the minimum rooms, then: return the actual room assignments.
  6. Count the number of subarrays with sum divisible by k.
  7. Merge k sorted lists; then: what if the lists are on different machines?
  8. Given a string and a dictionary, return all possible sentence segmentations (word break II).
  9. Find the k-th smallest element in a BST; then: with frequent inserts.
  10. Given n tasks with dependencies and durations, find the minimum total time with unlimited parallelism.

After each mock

Write down the two improvements from the feedback, practise exactly those (the relevant Part’s problem set or LeetCode list), and repeat the mock within a week. Track your scores over time. Note that this needs the Ask panel's API key to be configured, like the rest of Ask.
