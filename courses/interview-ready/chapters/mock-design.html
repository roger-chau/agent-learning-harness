How this works

Open the panel with Start the mock interview and type start. An AI interviewer runs a realistic system design round using the format, rubric and question bank below, giving hints only when you’re stuck. Type score me to end and get scored feedback against the rubric. Use New interview to reset. Treat it like the real thing: think aloud, and time yourself.

Format

45 minutes: one design question. Lead the conversation: requirements and numbers (5 min), API and data model, high-level design, deep dive on the bottleneck, failure modes.

Rubric

  • Requirements and estimation: asked the right questions, sized the load with numbers
  • Design: sensible components, each justified
  • Deep dive: found and resolved the real bottleneck
  • Trade-offs and failures: consistency, availability, failure handling, what to measure
  • Communication: drove the discussion, checked in, adapted

Question bank

  1. Design a rate limiter for a public API (100k requests/s across 50 gateway nodes).
  2. Design the market-data distribution system for a trading firm (one exchange feed → 200 strategy processes, microsecond latency).
  3. Design an LLM inference service for 10,000 requests/min with a 500 ms TTFT SLO.
  4. Design a metrics/monitoring pipeline for 100,000 hosts.
  5. Design a URL shortener.
  6. Design a distributed job scheduler for a GPU cluster.
  7. Design a news feed for 300M daily users.
  8. Design a key-value store with tunable consistency.

After each mock

Write down the two improvements from the feedback, practise exactly those (the relevant Part’s problem set or LeetCode list), and repeat the mock within a week. Track your scores over time. Note that this needs the Ask panel's API key to be configured, like the rest of Ask.
