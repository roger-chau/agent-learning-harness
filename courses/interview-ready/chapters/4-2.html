The signal

Dependencies: "before", "prerequisite", "must be built first", "ordering consistent with these rules", build systems, task scheduling, spreadsheet recalculation, the instruction scheduling you'll do as a compiler engineer. The graph is directed, and the questions are: is there a cycle (is it possible at all)? Give a valid order. What's the minimum number of rounds if independent tasks run in parallel?

The core idea

A directed graph has a topological order if and only if it has no cycle. Kahn's algorithm constructs one: a node with in-degree 0 has no unmet prerequisites, so it can go first. Remove it, decrement its successors' in-degrees, and repeat. If you run out of in-degree-0 nodes before placing them all, the remaining nodes contain a cycle.

The DFS version: a node's post-order finish time comes after all its descendants', so the reverse post-order is a topological order. Cycle detection uses three colours (unvisited, on the current path, finished); reaching a node that is on the current path means a back edge, which means a cycle.

Processing Kahn's frontier in layers gives the minimum number of parallel rounds, which equals the longest path in the DAG (the critical path). The frontier's data structure decides which valid order you get: a stack or queue gives any order, and a min-heap gives the lexicographically smallest.

The invariant and template

def topo(n, edges):                 # edge (u, v): u before v
    g = [[] for _ in range(n)]; indeg = [0] * n
    for u, v in edges:
        g[u].append(v); indeg[v] += 1
    frontier = [i for i in range(n) if indeg[i] == 0]   # invariant: all prerequisites placed
    order = []
    while frontier:
        u = frontier.pop()          # heapq.heappop for smallest order; layer by layer for rounds
        order.append(u)
        for v in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                frontier.append(v)
    return order if len(order) == n else None   # None: there is a cycle

Read the edge direction twice. In "[a, b] means take b before a", the edge is b → a. Getting this backwards still produces an order, just the reverse one, and passes symmetric examples. This is the single most common bug.

A thinking trace: alien dictionary

  1. Clarify: the words are sorted by an unknown alphabet. Return any consistent letter order (our version: the smallest), or "" if the input is contradictory.
  2. What information do we have? Sortedness constrains only adjacent words. That's a key reduction: n − 1 comparisons, not n².
  3. What does one comparison give? The first position where the two words differ: a before b means letter x precedes y. Nothing after that position tells us anything.
  4. Edge case to find early: if there is no differing position and the first word is longer ("abc" before "ab"), the input is invalid. Interviewers plant this.
  5. Now it's a solved problem: a graph on letters, then a topological sort. A cycle means "".
  6. Test: a single word (its letters in any order: in ours, sorted), duplicate constraints (don't double-count in-degree), and letters that appear but are unconstrained.

The habit: turn the story into a graph explicitly, saying "nodes are letters, edges come from first mismatches". Then the algorithm is a lookup, and you spend your time on the edge cases where the points are.

Traps and variations

  • Edge direction (see above), and duplicate edges inflating in-degrees.
  • Disconnected nodes with no edges must still appear in the order.
  • Recursive DFS in Python on 10⁵ nodes hits the recursion limit; Kahn is iterative by nature.
  • Longest path in a DAG (or DP over a DAG in general): process nodes in topological order and relax successors. This is how you get critical paths, the longest increasing path in a matrix, and the number of paths.
  • Minimum semesters with at most k courses per term is NP-hard in general. The interview version uses bitmask DP over small n. Know where the easy problem ends.
  • Compiler connection: list scheduling of instructions is Kahn's algorithm with a priority (critical-path length) on the frontier. You'll meet it again in the GPU course's compiler part.
