The signal

A process that moves between states where the next move depends only on the current state: random walks, board games, a frog on lily pads, a knight on a chessboard, a server's queue length, a market regime. The questions are where the process ends up (absorption), how long it takes (hitting times), and where it spends its time in the long run (the stationary distribution).

The core idea: two kinds of question, two tools

Transient questions (which absorbing state, how long until absorbed) are first-step analysis: one linear equation per state (Part 13.4). In matrix form, with Q the transient-to-transient block, the fundamental matrix N = (I − Q)⁻¹ gives expected visits, N·1 gives expected absorption times, and N·R gives absorption probabilities. That's the judged problem.

Long-run questions use the stationary distribution π with πP = π, Σπ = 1. For an irreducible, aperiodic chain, the fraction of time in state i → π_i and the expected return time to i is 1/π_i. For a random walk on an undirected graph, π_i = deg(i) / Σ deg (2 × edges), no equations needed.

The invariant and template

Absorption / hitting:   x_i = Σ_j P_ij x_j (+ 1 per step for times),   boundary values at absorbing states
Stationary:             π P = π, Σ π = 1        (solve the balance equations, or use symmetry/degrees)
Detailed balance:       π_i P_ij = π_j P_ji     (if it holds, π is stationary: an easy check for reversible chains)
Return time:            E[return to i] = 1 / π_i
n-step distribution:    p_n = p_0 · Pⁿ          (matrix power: Part 8.5)

A thinking trace: a knight on a chessboard

A knight moves uniformly at random among its legal moves, starting in a corner. Expected number of moves to return to that corner?

  1. Model: a random walk on the knight's-move graph of 64 squares. It's undirected, so π_i = deg(i) / (2E).
  2. Degrees: knight moves per square: corners 2, edge-adjacent squares 3 and 4, the inner region 6 and 8. Summing over the board gives Σ deg = 336 (168 edges).
  3. Stationary probability of the corner: 2/336 = 1/168.
  4. Return time: 1/π = 168 moves. No linear system with 64 unknowns needed.
  5. Sanity: corners are hard to reach (only 2 entry squares), so a long return time makes sense.

The habit: before setting up equations, ask whether the chain is a walk on an undirected graph or has a symmetry. Long-run questions often have one-line answers.

Traps and variations

  • Periodicity: a walk on a bipartite graph alternates sides, so Pⁿ doesn't converge, though time averages still do.
  • Reducible chains have several stationary distributions; first find the closed classes.
  • Expected time vs probability: for times, add 1 per step and set 0 at the targets; for probabilities, use 0/1 boundaries and no +1.
  • Collapse states by symmetry: a die-rolling "how many distinct faces seen" chain has 7 states, not 2⁶.
  • Market regimes: a 2-state (calm/volatile) chain with switching probabilities a, b has π = (b/(a + b), a/(a + b)).
